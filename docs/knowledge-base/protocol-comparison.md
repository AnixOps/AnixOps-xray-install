# 协议对比与选择指南

AnixOps 目前支持两种协议，各有优势。本文帮助你选择最适合的协议。

## 快速对比

| 特性 | VLESS + Reality | Hysteria2 |
|------|-----------------|-----------|
| 传输层 | TCP | UDP (QUIC) |
| 需要域名 | 不需要 | 不需要 |
| 伪装效果 | 像正常 HTTPS 访问 | 像正常 HTTPS 流量 |
| 延迟 | 中 | 低 |
| 吞吐量 | 高 | 极高 |
| 抗检测 | 强 | 强 |
| 游戏支持 | 一般 | 优秀 |
| 视频支持 | 优秀 | 优秀 |
| 客户端兼容 | V2RayN, Clash, Sing-box, Shadowrocket | Clash, Sing-box, Nekoray |
| 部署难度 | 中 | 低 |

## 详细分析

### VLESS + Reality + gRPC

**原理**: 基于 Xray 的 Reality 协议，将代理流量伪装成对目标网站（如 addons.mozilla.org）的正常 TLS 连接。gRPC 传输层进一步将流量伪装成正常的 API 调用。

**优势**:
- **无需域名**: Reality 协议不依赖自己的域名和 TLS 证书
- **抗指纹识别**: 使用 utls 库模拟 Chrome 浏览器的 TLS 指纹，无法通过 JA3 指纹识别
- **抗主动探测**: 无法通过 TLS 握手探测是否为代理服务器
- **兼容性好**: VLESS 协议成熟稳定，多数客户端支持

**劣势**:
- 基于 TCP，延迟略高于 UDP
- 在某些严格网络环境下可能被 QoS 限速

**推荐场景**:
- 日常浏览、视频、下载
- 对稳定性要求高的场景
- 首次使用的用户

### Hysteria2

**原理**: 基于 QUIC (UDP) 协议，内置拥塞控制算法（BBR），在弱网环境下表现极佳。

**优势**:
- **极致速度**: UDP 无握手延迟，BBR 算法充分利用带宽
- **游戏友好**: 低延迟，UDP 原生支持
- **抗丢包**: 在高丢包率网络下仍能保持良好速度
- **混淆支持**: 内置 Salamander 混淆，进一步隐藏流量特征

**劣势**:
- 客户端兼容性稍差（不支持 Shadowrocket 原生）
- 部分网络环境可能限制 UDP 流量

**推荐场景**:
- 游戏加速
- 视频直播/高码率视频
- 弱网环境（高延迟、高丢包）
- 追求极致速度的用户

## 选择建议

```
你是首次使用？
  ├── 是 → VLESS Reality (最稳妥)
  └── 否 → 你主要用来做什么？
            ├── 打游戏 → Hysteria2
            ├── 看视频 → 两者均可，Hysteria2 略优
            ├── 日常浏览 → VLESS Reality
            └── 追求极致速度 → Hysteria2
```

## 可以同时使用吗？

按租模式下，每次租赁只能选择一个协议。如果需要切换，可以销毁当前节点后重新租赁。

自托管模式下，可以同时部署两种协议到同一台 VPS（需不同端口）。
